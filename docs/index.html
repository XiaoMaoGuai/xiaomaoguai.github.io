环境信息管理系统 ​

本系统用于管理各个业务系统在不同环境下的数据库、Redis等配置信息，包括但不限于以下系统：

系统列表 ​

  • 风控决策系统
  • 资信系统

环境说明 ​

  • 开发环境：供开发人员日常开发使用
  • SIT环境：系统集成测试环境
  • UAT环境：用户验收测试环境
  • PRE环境：预生产环境
  • PRD环境：生产环境

搜索使用说明 ​

本系统提供强大的搜索功能，帮助您快速定位需要的环境信息：

  1. 点击页面右上角的搜索图标或使用快捷键 Ctrl + K（Windows/Linux）或 ⌘ + K（Mac）
  2. 在搜索框中输入关键词，如系统名称、环境名称、数据库类型等
  3. 支持多关键词组合搜索，如"风控 MySQL SIT1"
  4. 支持模糊搜索，输入部分关键词也能找到相关结果
  5. 搜索结果会显示匹配页面的标题和简要描述

搜索示例 ​

  • 查找特定系统环境：风控 开发环境1
  • 查找特定数据库信息：资信 MongoDB
  • 查找Redis配置：Redis SIT
  • 查找测试账号：测试账号 admin

提示：为了提高搜索效率，建议使用具体且唯一的关键词

使用说明 ​

  • 可通过页面顶部的搜索功能查找特定环境信息，如数据库地址、账号等
  • 支持中文搜索，输入关键词即可快速定位相关信息
