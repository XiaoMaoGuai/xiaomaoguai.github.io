风控决策系统环境配置 ​

本页面集中管理风控决策系统在各个环境中的配置信息，包括数据库、Redis等连接信息。

环境列表 ​

  • 开发环境1

注意事项 ​

  1. 请勿将生产环境的敏感信息外泄
  2. 账号密码使用前请核对环境，避免误操作
  3. 如发现配置信息有误，请联系管理员更新

使用说明 ​

  • 可通过页面顶部的搜索功能快速查找特定环境信息
  • 搜索示例：
    • 搜索"风控 MySQL 开发环境"可找到开发环境中的MySQL配置
    • 搜索"SIT Redis"可找到SIT环境中的Redis配置
    • 搜索特定账号、密码或连接字符串可快速定位
